# perrin's homepage

简体中文 | [English](./README_EN.md)

个人主页与常用链接入口，基于 Vue 3 + Vite 构建。

- 主页：[hyperrin.com](https://hyperrin.com)
- 博客：[blog.hyperrin.com](https://blog.hyperrin.com)
- GitHub：[Pengyang233](https://github.com/Pengyang233)

## 本地运行

使用 Node.js 和 npm：

```bash
npm ci
npm run dev
npm run build
```

复制 `.env.example` 为 `.env`，按需修改站点名称、描述、天气和音乐配置。网站导航和社交链接分别在 `src/assets/siteLinks.json` 与 `src/assets/socialLinks.json` 中设置，头像及站点图标位于 `public/images/icon/`。
